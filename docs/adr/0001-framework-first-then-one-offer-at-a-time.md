# Build the company framework first, then generate one Offer at a time

The dataset is not generated in one pass. We first fix the fictional company (operating structure, people, rates, catalogue, rules, regulations) and then generate the documents behind each Offer, from first contact to final total, one Offer at a time with a review before the next. This keeps documents consistent with each other and makes every Offer traceable, at the cost of a slower growing dataset.
